【先搞清楚: 两套东西, 完全分开】

    ┌ 自定义 UI (你的 HUD 长什么样)  →  放在  EXPAS\layouts\   目录
    └ VIP 音乐盒 (回合第一名放你的曲子) →  放在  EXPAS\mvp_music\ 目录

   两边的 JS 写法差不多, 但**放的位置不同、作用不同、互不影响**。
   你可以只做其中一样, 也可以两样都做。

第 1 节  JS 文件怎么写
================================================================================

  【1.1 自定义 UI 的 JS】—— 属于 layouts\ 目录

      // owner = 76561198000000000
      const owner = "76561198000000000";
      const name = "示例专属布局";

      const rows = [
        "row|center|0|欢迎 {name} 进入到 {server}",
        "row|center|32|今天已游玩 {playtime}   现在是 {tz} {clock}",
        "row|center|64|本回合伤害 {roundDmg}   总伤害 {totalDmg}",
        "level|right|40|Lv.{level}   经验 {exp}/{expNeed}",
        "level|right|16|还差 {expNeed} 经验"
      ];

  【1.2 VIP 音乐盒的 JS】—— 属于 mvp_music\ 目录(和上面那份不是一个东西!)

      // owner = 76561198000000000
      const owner = "76561198000000000@steam";
      const audio = "示例开场曲.wav";

      · owner = 你的 Steam64
      · audio = 音频文件名(和这个 JS 放在同一个 mvp_music\ 目录里)
                也允许写完整路径, 例如  const audio = "D:\\SCP音频\\示例开场曲.wav";
      · 变量名还认 music / file / path / wav, 意思一样

  【1.3 JS 写法的 5 条规则(两套通用)】
    1. `//` 开头的行 = 注释, 会被忽略
       —— **例外**: 带 owner 的注释行会被读, 所以 `// owner = 数字` 是有效的
    2. **双引号 / 单引号里的文字才是内容**, 插件只把这些字符串一条条拿出来用
    3. 只认这几种赋值:  owner / name / rows(布局行) / audio(music/file/path/wav)
       其它变量名一律忽略
    4. 一行里可以放多个字符串, 会被逐条拆开
    5. ★ **不能写逻辑**: `if` / `for` / 拼接(`"a" + "b"`) 都不会生效, 只会被丢掉。
       这只是"用 JS 的壳装文本", 游戏**不会执行**这个 JS

  【1.4 硬性要求】
    · 文件存成 **UTF-8(不要带 BOM)**, 否则中文会变乱码
    · 文件名用你的 Steam64:  `76561198000000000.js`

第 2 节  TXT 格式怎么填(不想写代码就用这个)
================================================================================

  【2.1 自定义 UI 用 TXT —— layouts\76561198000000000.txt】

      # owner = 76561198000000000
      name = 示例专属布局

      row|center|0|欢迎 {name} 进入到 {server}
      row|center|32|今天已游玩 {playtime}   现在是 {tz} {clock}
      row|center|64|本回合伤害 {roundDmg}   总伤害 {totalDmg}
      level|right|40|Lv.{level}   经验 {exp}/{expNeed}
      level|right|16|还差 {expNeed} 经验

  【2.2 VIP 音乐盒用 TXT —— mvp_music\76561198000000000.txt】

      # owner = 76561198000000000
      audio = 示例开场曲.wav

  【2.3 TXT 规则】
    1. 一行一条, 空行忽略
    2. `#` 开头的整行是注释
       —— **例外**: `# owner = 数字` 会被读(这是归属标记)
    3. 排版行用竖线 `|` 分 4 段:  类型 | 对齐 | 偏移 | 文字
    4. `name = …` / `audio = …` 是设置行, 不能带 `|`
    5. 文字里可以写颜色和占位符(见第 3 节)
    6. 行首的 `#` 才是注释; 想让 `#` 当正文(如 `#1 欢迎…`)直接写就行;
       要行内注释就在 `#` 前打空格:  `row|center|0|文字  #后面不要了`

  【2.4 硬性要求】
    · 存成 **UTF-8(不要带 BOM)** —— 最容易出错的一条
    · 文件名用你的 Steam64: `76561198000000000.txt`

第 3 节  UI 怎么自定义(排版语法)
================================================================================

  【每行格式】
      类型|对齐|垂直偏移|文字

  【① 类型 —— 只能这 5 个】
    row     主块的一排       默认贴在屏幕**最下方居中**          ← 常用
    level   等级块的一排     默认在**右下角**, 比主块更靠上      ← 常用
    kill    击杀确认块       只在击杀后显示几秒, 平时不显示
    fold    HUD 折叠单行     玩家把面板里「HUD 折叠」切成折叠时显示这一行
    custom  插入位置         不写文字, 表示"这里插入服务器公共自定义行"
                             例:  custom|center|80

  【② 对齐 —— 只能这 3 个】
    left 左      center 居中      right 右

  【③ 垂直偏移 —— 整数, 单位像素】
    · ★★ **数字越大越靠上**; 想往屏幕下面挪就写**负数**
    · 同一块内多行, 插件自动按"偏移从大到小"从上往下排
      → 想让 A 在 B 上面, 就让 A 的偏移比 B 大
    · 推荐间距 **32**(字大就 40~48)
    · 主块示例: 0 / 32 / 64 / 96     (0 在最下, 96 在最上)
    · 等级块建议正数(16 / 40), 它本来就在主块上方

  【④ 文字】
    · 上色:  `<color=#FFD700>这是金色</color>`    (HEX 必须大写)
    · 用占位符(下表), 游戏里会替换成你的实时数据

  【可用占位符】
    你的名字 {name}          服务器名 {server}
    游玩天数 {days}          游玩小时 {hours}
    时区 {tz}                当前时间 {clock}
    累计游玩 {playtime}
    本回合伤害 {roundDmg}    当前角色伤害 {roleDmg}
    累计总伤害 {totalDmg}    累计总经验 {totalExp}
    等级 {level}             当前经验 {exp}        差多少升级 {expNeed}
    击杀 {kills}             死亡 {deaths}         积分 {points}
    本回合积分 {roundPoints}
    最近击杀 {killName} {killDamage} {killShare} {killPoints}
    被击杀的角色 {killRole}   角色类型 {killRoleKind}(人形/SCP/人机)
    本回合时长 {roundTime}   存活人数 {aliveCount}  服务器TPS {tps}
    存活SCP {scpCount}       回合序号 {roundId}
    版本 {version}           状态图标 {icons}      屏幕比例 {aspect}
    排行榜 {mvpName} {mvpDamage} {mvpLevel} {topList}

    ★ 名字写错不会被替换, 会**原样显示** —— 交给我前自己读一遍

  【排版建议】
    · 总共不超过 12 行; 等级块 1~3 行就够
    · 主块最下面一行别贴屏幕边缘(偏移别写太小的负数)
    · 先交最简单的版本, 进服看效果再慢慢调

  【你什么时候能看到】
    服务器按**文件名里的 17 位 Steam64**(或首行 owner)判断归属。
    对上了 → 你进服 ESC → 设置 → 服务器设置 → EXPAS, 「自定义 UI」下拉里就有你自己的布局;
    其他玩家看不到它。

第 4 节  VIP 音乐盒(回合第一名专属音乐)
================================================================================

  【效果】
    每回合结束时, 系统统计**本回合造成伤害第一名**的玩家。
    如果是你, 系统就拿你的 Steam64 去 **mvp_music\ 目录里检索 JS 文件**;
    匹配到你的那个 JS, 就按里面写的路径播放对应音频, 全服都能听到。

  【你要提供两样】
      ① 你的 **Steam64**(17 位数字)
      ② 一个**音频文件**

    → 音频我会放进服务器的  EXPAS\mvp_music\  目录,
      同时在该目录写一个 `<你的Steam64>.js`, 内容就是:
          const owner = "你的Steam64";
          const audio = "你的音频文件名.wav";
      (你也可以自己写好这个 JS 交给我, 格式见第 1.2 节)

  【音频格式要求】
    · **支持格式**: OGG / MP3 / M4A / AAC / MP4 / FLAC / WAV / WMA / OPUS / AIFF / APE / MKA / WEBM
      (插件内置了自建的原生 DLL 解码器, 首次使用时自动释放到 EXPAS\bin\native\,
       不依赖任何外部 exe)
    · **WAV 建议 PCM 16bit** —— 这是唯一走内置快速解码的格式, 最省资源
    · 采样率任意(会自动转成 48000Hz); 单声道 / 立体声都行(会自动混成单声道)
    · **时长建议 10~60 秒** —— 太长影响回合节奏, 一般是开场/高潮片段
    · 文件名别用特殊符号:  `\ / : * ? " < > |`  都不行
    · 文件别太大

  【音频怎么放】
    由我放到  %APPDATA%\SCP Secret Laboratory\LabAPI\configs\7777\EXPAS\mvp_music\
    (音频和那个 JS 在同一个目录里; JS 里的 audio 写文件名即可)

  【自检】
    我部署完会跑  `EXPAS mvpmusic list`, 它会列出每条 JS 与"文件存在 / 文件缺失"。

第 6 节  常见问题
================================================================================

  现象                        原因 / 怎么办
  -------------------------   -------------------------------------------------
  面板里没有「自定义 UI」     没重启服务器; 或投稿里的 Steam64 不对
  选了布局没变化              布局文件名和你的 Steam64 不一致(归属对不上)
  中文全是乱码                文件不是 UTF-8 → 重存成 UTF-8(不要带 BOM)
  某一行没显示                那行 `|` 段数不够 4 段, 或类型/对齐写错
  文字被屏幕边缘切掉          偏移写太满; 往下别贴 0, 往上别超过 200
  占位符原样显示了            名字拼错了(对照第 3 节的表)
  音乐盒不响                  音频格式不支持(见第 4 节) / 音频没放进 mvp_music\ / 没有你的 JS
  我不是第一名也想要音乐        音乐盒只在"本回合伤害第一"时触发, 设计如此

附录 B  给我自己(管理员)的操作备忘
================================================================================

  【两套文件, 位置不同】
    自定义 UI  →  EXPAS\layouts\<Steam64>.txt          (也支持 .js)
    VIP 音乐盒 →  EXPAS\mvp_music\<Steam64>.js         (声明 owner + audio)
                   EXPAS\mvp_music\<音频>.wav           (音频放同一目录)

  脚本三件套(本目录):
    玩家投稿填写说明.txt   ← 本文档, 可整份转发给玩家
    部署投稿.js            ← 导入脚本(Node, 零第三方依赖)
    部署投稿.bat           ← 双击运行 / 也可把收件夹拖到它上面

  收件夹:  C:\Users\35762\Desktop\EXPAS投稿\
  目标:    %APPDATA%\SCP Secret Laboratory\LabAPI\configs\7777\EXPAS\

  脚本做的 4 件事:
    ① 读收件夹的 *.txt / *.js, 取 owner / name / 排版行 / music
    ② 有排版行 → 写 layouts\<Steam64>.txt
    ③ 有 music(文件名) → 复制音频到 mvp_music\ + 写 mvp_music\<Steam64>.js
       music 写绝对路径  → 不复制, 直接把该路径写进 mvp_music\<Steam64>.js
    ④ 打印汇总

  ★ 脚本**不再改 config.yml** —— 音乐盒已改为 JS 文件驱动。

  跑法:
    双击 部署投稿.bat
    或:  node 部署投稿.js
         node 部署投稿.js --dry       ← 只检查不写文件, 建议先跑

  【运行原理(写给未来的自己)】
    回合结束 → 结算 MVP(伤害第一) → 用其 Steam64 调 PlayMvpMusicFor:
      ① 扫描  mvp_music\*.js / *.txt, 建 "Steam64 → 音频路径" 索引(每次重扫, 改完即时生效)
      ② 命中 → 按 JS 里 audio 填的路径播放(相对 mvp_music\ 或绝对路径)
      ③ 没命中就什么都不放
    播放走**隐藏音箱**(远处高空的一个非空间化音源, 全服都能听到)。
    ★ 不会生成任何假人/bot —— 玩家列表里不会多出多余的条目。

  【自检命令】
    EXPAS mvpmusic list         列出音乐盒 JS 条目 + 文件存在/缺失 + 未被引用的音频
    EXPAS mvpmusic play <玩家>   手动试播一次
    EXPAS layout list           列出已载入的 UI 布局

  ★ 注意事项:
    · 投稿/JS/TXT 一律 **UTF-8(无 BOM)**; 音频支持 OGG/MP3/AAC/M4A/MP4/FLAC/WAV/WMA 等(详见第 4 节)
    · 自建原生解码器(EXPAS.AudioCodec.dll + ffmpeg 共享库)内嵌在 EXPAS.NP.dll 里,
      首次用到时自动释放到 EXPAS\bin\native\(共 6 个 DLL, 约 2.5 MB), **不需要任何 exe**
    · 若把原生解码器删了又想要后备方案: 可在 config.yml 的 ffmpeg_path 指定一个 ffmpeg.exe,
      或把 ffmpeg.exe 放到 EXPAS\bin\ 里(纯可选, 正常情况下用不到)
    · 改完必须**重启服务器**才生效
    · 环境需要 Node.js(https://nodejs.org/)
